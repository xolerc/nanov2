# XOLƎRIƆ BLACK GLASS (nanov2)

A hardcore tile-matching puzzle game. Match pairs of identical tiles connected by a path with at most 2 turns. Features special tiles, a combo system, and math-based lockdown puzzles on error.

## Features
- 8×8 grid with 70+ emoji tile types
- Path-finding algorithm with ≤2 turn constraint
- Special tiles: lightning, bomb, frozen, locked
- Combo multiplier with timed decay
- Lockdown math puzzles on error
- Hint and shuffle actions
- Animated match effects and particles
- Progressive difficulty across levels

## How to open
Open `index.html` in any modern browser.
